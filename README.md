# 启灵bbs (Qibbs Community)

> 现代化、轻量高效的 WordPress 微社区互动与工单系统插件，深度适配启灵主题生态。

---

## 📖 项目简介

**启灵bbs（Qibbs Community）** 是一款专为 WordPress 打造的高性能现代化微社区与综合服务插件。不仅支持高颜值瀑布流/卡片式社区动态、话题讨论、悬赏互动、点赞收藏与每日打卡签到，还内建了专业的技术工单与客户支持系统，并拥有完善的 UID 靓号交易、道具商城、积分成长及红包玩法，为站点提供全方位的社区化运营赋能。

---

## ✨ 核心功能亮点

- 💬 **轻量微社区**：支持图文多媒体发帖、卡片与瀑布流动态、多版块/话题聚合、精选置顶、点赞与深度评论互动。
- 🎫 **专业工单系统**：工单提交、工单分类流转、进度实时追踪与多端推送通知，让售后与技术支持井井有条。
- 🎁 **丰富互动玩法**：每日签到打卡、社区抢红包、悬赏问答与徽章成就激励体系。
- 💎 **UID 靓号与 C2C 市场**：独创 UID 靓号池系统，支持靓号规则分配、商城兑换及站内自由 C2C 交易流转。
- 🎒 **道具背包与积分**：道具商城、卡券背包、多阶成长经验与积分体系联动，打造高黏性用户生态。
- 🛡️ **安全风控与审核**：内置敏感内容审查、风控拦截机制与版主协同管理体系。
- 📱 **多端全响应式**：原生移动端极致体验适配，无缝对接启灵主题，亦可自适应主流标准 WordPress 主题。

## 🚀 环境要求与安装指南

### 环境要求
- **WordPress**：6.0 或更高版本
- **PHP**：8.0 或更高版本
- **MySQL / MariaDB**：5.7+ / 10.3+

### 快速安装
1. 下载最新发行包或通过 Git 克隆到 WordPress 插件目录：
   ```bash
   cd wp-content/plugins/
   git clone https://github.com/your-username/qibbs-community.git
   ```
2. 进入 WordPress 管理后台 -> **插件** -> **已安装的插件**，找到 **启灵bbs** 点击 **启用**。
3. 启用后在后台侧边栏进入 **启灵社区** 即可完成各模块参数配置与使用。
